NGL Risk Premia — Value Contract Sensitivity

Products: Ethane, Propane, Butane, Isobutane, Ethylene, Propylene (Argus). Baseline: Value anchored on F8 (same as every other asset class). This report reruns the entire pipeline — all 4 individual strategies (NGL has a single Carry tenor pair, F4-F15, not Metals' two-tier structure, so there are 4 strategies here, not 6), all 4 portfolio combine methods, full-sample/regime/expanding-window tables — three more times, each time with Value's anchor contract changed to F2, then F3, then F4. F1 is deliberately excluded from this sensitivity study: NGL's own front-month convention (established elsewhere in this project, e.g. ngl_dashboard/app.py and scripts/generate_tradebooks.py) treats the sheet's literal F1 column as too stale/index-settled to trade for NGL products — the continuous roll-adjusted series used for Momentum/PnL already skips it (f1_col/f2_col point at the sheet's F2/F3 columns instead). Testing Value on F1 would replicate a contract this project has already decided not to trade for this asset class, so F2 is the nearest contract actually tested here. Momentum, the single Carry tenor pair (F4-F15), and the single Carry-Momentum tenor pair (F4-F15) are held EXACTLY as locked in research/configs/ngl.py — only VALUE_CONTRACT changes. Lookback (1260d), threshold (±10%), and execution lag (shift_n=2) are unchanged from the F8 baseline in every variant.

StatArb caveat: research/configs/ngl.py sets STATARB_ENABLED = True (NGL shares an 8-spread cross-asset StatArb sleeve with Energy, per Bogorad's own design). This report, like the Metals and Precious Metals sensitivity reports before it, is built entirely on research/run_regime_table.py's pipeline, which only ever constructs Momentum/Carry/CarryMom/Value — it does not include StatArb regardless of this flag. So this report covers those 4 strategies only; StatArb is out of scope here, not omitted by oversight.

1. Overview — what's varied, what's fixed, why F1 is excluded 2. Variant deep dives (tabbed: F2 / F3 / F4) 3. Side-by-side comparison (F8 baseline vs F2 vs F3 vs F4) 4. Findings / synthesis

1. Overview

Value is a long-run mean-reversion signal: it compares one point on the futures curve to that same point's own trailing moving average, and bets the price reverts toward that average when the deviation is large enough to clear a threshold. The baseline uses F8 as the anchor, the same convention as every other asset class in this project. Moving the anchor to F2, F3, or F4 asks whether a nearer-dated point on the NGL curve mean-reverts to its own 5-year moving average in a similar way to F8's further-out, more curve-structural read — while F1 itself is excluded from the test entirely, for the front-month staleness reason above.

1.1 What's held fixed across all four variants (F8 baseline, F2, F3, F4)

  • Momentum: 3-way MA-crossover composite, (1,20)/(5,60)/(20,250), shift_n=1
  • Carry V1(Level)+V2(Z-score) composite: single tenor pair F4-F15 (Bogorad's own NGL convention), z-window=252, shift_n=1
  • Carry-Momentum (V3): F4-F15 tenor pair, horizon=20, shift_n=1
  • Value lookback (1260d), threshold (±10%), execution lag (shift_n=2) — only the anchor CONTRACT changes
  • Transaction cost: 5bps round-trip. Products: Ethane, Propane, Butane, Isobutane, Ethylene, Propylene, equal-weighted. Regimes: R1 Supercycle Unwind (2011-2015), R2 Recovery/Stabilization (2016-2019), R3 COVID Shock (2020-2021), R4 Post-COVID/Russia-Ukraine (2022-2026). Portfolio: the same 4-sleeve "all reference strategies" aggregate used throughout this project — Equal Weight, Inverse Vol (63d), Risk Parity (ERC, rolling 252d/21d rebal), and Return-Tilt ERC (tilt=0.5, illustrative midpoint) combining the four strategy-level series (Momentum, Carry F4-F15, CarryMom F4-F15, Value).

Expanding-window tables here use the same convention as the Metals/Precious sensitivity reports: cumulative-sample performance snapshots through each regime boundary (2011→2015, 2011→2019, 2011→2021, 2011→latest), NOT a train/test split — these are fixed ex-ante rule-based signals, nothing is refit between windows.

4. Findings / synthesis

Unlike Metals, moving Value's anchor toward the front of the NGL curve does NOT improve Value's own standalone IR — it is F8 that is the strongest of the four: F8 (0.330) > F3 (0.260) > F4 (0.251) > F2 (0.213). The gap is modest in absolute terms (roughly 0.1-0.12 IR from best to worst) but the direction is the opposite of the Metals finding, where F1 (nearest to front) was the best and F8 the worst. NGL's further-out F8 anchor appears to carry a more genuine long-run "fair value" signal for this asset class than a point closer to the front, not less.

The regime pattern shifts in R3 (COVID) depending on the contract: at F8, Value's COVID-era IR is mildly positive (+0.124); at F2/F3/F4 it turns negative (F2: -0.283, F3: -0.099, F4: -0.054). This is the opposite of what stayed constant in the Metals study (where the R3-negative pattern held across every contract) — here, the anchor choice actually flips the sign of one regime's contribution, worth flagging as a genuine sensitivity rather than a rounding artifact.

None of this changes the portfolio-level headline for NGL: every combine method is strongly positive in every variant. Equal Weight ranges 1.273 to 1.289, Inverse Vol 1.221 to 1.291, Risk Parity (ERC) 1.060 to 1.180, and Return-Tilt ERC 1.111 to 1.230 across all four Value variants — a striking contrast with Metals, where no combine method cleared zero in any variant. NGL's portfolio strength is driven primarily by Momentum and Carry-Momentum (both far stronger standalone than Value in every variant, see the individual-strategy tables in each tab), so Value's own contract choice is a second-order lever here, not the swing factor it looked like in the Metals sensitivity study.

Caveat: Value's own full-sample IR is modest-to-weak in absolute terms across all four NGL variants (0.21 to 0.33), well below Momentum's (1.25) and CarryMom's (0.87) full-sample IR at F8. Read this report as "does the choice of Value anchor matter for NGL" (answer: yes, direction-wise, but the effect size is small and Value is not the strategy driving NGL's portfolio result either way) rather than as evidence that any of these four Value variants is a strong standalone NGL signal.
