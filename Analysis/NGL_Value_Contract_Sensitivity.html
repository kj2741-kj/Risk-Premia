NGL Risk Premia — Value Contract Sensitivity

Products: Ethane, Propane, Butane, Isobutane, Ethylene, Propylene (Argus). Baseline: Value anchored on F8 (same as every other asset class). This report reruns the entire pipeline — all 6 individual strategies (NGL now has TWO Carry tenor pairs as of 2026-08-03: F2-F4 (short-term, newly added) and F2-F14 (changed the same day from F4-F15, for a 12-month rather than 11-month span) — matching Metals'/Energy's two-tier structure, so there are 6 strategies here now, not 4), all 4 portfolio combine methods, full-sample/regime/expanding-window tables — three more times, each time with Value's anchor contract changed to F2, then F3, then F4. F1 is deliberately excluded from this sensitivity study: NGL's own front-month convention (established elsewhere in this project, e.g. ngl_dashboard/app.py and scripts/generate_tradebooks.py) treats the sheet's literal F1 column as too stale/index-settled to trade for NGL products — the continuous roll-adjusted series used for Momentum/PnL already skips it (f1_col/f2_col point at the sheet's F2/F3 columns instead). Testing Value on F1 would replicate a contract this project has already decided not to trade for this asset class, so F2 is the nearest contract actually tested here. Momentum, the two Carry tenor pairs (F2-F4, F2-F14), and the two Carry-Momentum tenor pairs (same two) are held EXACTLY as locked in research/configs/ngl.py — only VALUE_CONTRACT changes. Lookback (1260d), threshold (±10%), and execution lag (shift_n=2) are unchanged from the F8 baseline in every variant.

Carry tenor caveat (2026-08-03): this report was originally built on NGL's F4-F15 Carry tenor pair, then regenerated once on F2-F14 alone, and is now regenerated AGAIN to add a second, short-term tenor pair (F2-F4) alongside F2-F14 — NGL has 6 strategies now, matching Metals'/Energy's two-tier shape. Momentum and Value's own standalone numbers are unaffected by any of this (they don't depend on the Carry tenor), but Carry, Carry-Momentum, and all 4 portfolio combine methods (which mix every strategy together) changed again. Neither F2-F4 nor F2-F14 has been re-verified for liquidity or the near-tenor heating-season seasonality concern that originally motivated F4 over F1/F2 as the near leg (see research/configs/ngl.py and ngl_dashboard/app.py for the full caveat) — treat both Carry tenors as provisional pending that re-check.

StatArb caveat: research/configs/ngl.py sets STATARB_ENABLED = True (NGL shares an 8-spread cross-asset StatArb sleeve with Energy, per Bogorad's own design). This report, like the Metals and Precious Metals sensitivity reports before it, is built entirely on research/run_regime_table.py's pipeline, which only ever constructs Momentum/Carry/CarryMom/Value — it does not include StatArb regardless of this flag. So this report covers those 4 strategies only; StatArb is out of scope here, not omitted by oversight.

1. Overview

Value is a long-run mean-reversion signal: it compares one point on the futures curve to that same point's own trailing moving average, and bets the price reverts toward that average when the deviation is large enough to clear a threshold. The baseline uses F8 as the anchor, the same convention as every other asset class in this project. Moving the anchor to F2, F3, or F4 asks whether a nearer-dated point on the NGL curve mean-reverts to its own 5-year moving average in a similar way to F8's further-out, more curve-structural read — while F1 itself is excluded from the test entirely, for the front-month staleness reason above.

1.1 What's held fixed across all four variants (F8 baseline, F2, F3, F4)

  • Momentum: 3-way MA-crossover composite, (1,20)/(5,60)/(20,250), shift_n=1
  • Carry V1(Level)+V2(Z-score) composite: TWO tenor pairs, F2-F4 (short-term, added 2026-08-03) and F2-F14 (changed 2026-08-03 from F4-F15, Bogorad's own NGL convention originally), z-window=252, shift_n=1
  • Carry-Momentum (V3): same two tenor pairs (F2-F4, F2-F14), horizon=20, shift_n=1
  • Value lookback (1260d), threshold (±10%), execution lag (shift_n=2) — only the anchor CONTRACT changes
  • Transaction cost: 5bps round-trip. Products: Ethane, Propane, Butane, Isobutane, Ethylene, Propylene, equal-weighted. Regimes: R1 Supercycle Unwind (2011-2015), R2 Recovery/Stabilization (2016-2019), R3 COVID Shock (2020-2021), R4 Post-COVID/Russia-Ukraine (2022-2026). Portfolio: the same 6-sleeve "all reference strategies" aggregate used throughout this project — Equal Weight, Inverse Vol (63d), Risk Parity (ERC, rolling 252d/21d rebal), and Return-Tilt ERC (tilt=0.5, illustrative midpoint) combining the six strategy-level series (Momentum, Carry F2-F4, Carry F2-F14, CarryMom F2-F4, CarryMom F2-F14, Value).

Expanding-window tables here use the same convention as the Metals/Precious sensitivity reports: cumulative-sample performance snapshots through each regime boundary (2011→2015, 2011→2019, 2011→2021, 2011→latest), NOT a train/test split — these are fixed ex-ante rule-based signals, nothing is refit between windows.

4. Findings / synthesis

Unlike Metals, moving Value's anchor toward the front of the NGL curve does NOT improve Value's own standalone IR — it is F8 that is the strongest of the four: F8 (0.330) > F3 (0.260) > F4 (0.251) > F2 (0.213). This part is unchanged from every prior version of this report, since Value's own computation does not depend on the Carry tenor at all. The gap is modest in absolute terms (roughly 0.1-0.12 IR from best to worst) but the direction is the opposite of the Metals finding, where F1 (nearest to front) was the best and F8 the worst.

The regime pattern shifts in R3 (COVID) depending on the contract: at F8, Value's COVID-era IR is mildly positive (+0.124); at F2/F3/F4 it turns negative (F2: -0.283, F3: -0.099, F4: -0.054). Also unchanged from prior versions.

New this pass: the short-term Carry tenor (F2-F4) is meaningfully weaker than the long tenor (F2-F14), standalone. Carry (F2-F4) full-sample IR is +0.272, roughly half of Carry (F2-F14)'s +0.589; Carry-Momentum (F2-F4) is +0.519 vs CarryMom (F2-F14)'s +0.869. F2-F4's own regime pattern is also choppier — positive in R1/R2/R4 (0.609/0.144/0.305) but negative in R3 COVID (-0.105), where the long tenor is instead NGL's single strongest cell (+1.544). Adding this short-term sleeve is a genuine diversifier in principle (different regime behavior from the long tenor) but is not, on its own, a strong signal the way F2-F14 already was.

Portfolio-level effect of adding the F2-F4 sleeve: every combine method's IR dropped materially (from roughly 1.2-1.4 down to roughly 1.05-1.14), but every method stays comfortably positive in every Value variant. Equal Weight now ranges 1.121-1.135 (was 1.310-1.328 with 4 strategies), Inverse Vol 1.065-1.102 (was 1.312-1.368), Risk Parity (ERC) 1.048-1.115 (was 1.169-1.254), Return-Tilt ERC 1.085-1.135 (was 1.206-1.287) — a real dilution from folding in a weaker sleeve via equal/near-equal weighting, not a data or computation issue. NGL's portfolio conclusion is unchanged qualitatively (strongly positive everywhere, a striking contrast with Metals where no combine method ever clears zero), but the magnitude is now visibly lower than either single-Carry-tenor version of this report showed. NGL's portfolio strength is still driven primarily by Momentum and Carry-Momentum (F2-F14) — Value's own contract choice remains a second-order lever, and now so does the new F2-F4 sleeve.

Caveat: Value's own full-sample IR is modest-to-weak in absolute terms across all four NGL variants (0.21 to 0.33), well below Momentum's (1.25) and CarryMom (F2-F14)'s (0.87) full-sample IR at F8. Read this report as "does the choice of Value anchor matter for NGL" (answer: yes, direction-wise, but the effect size is small and Value is not the strategy driving NGL's portfolio result either way) rather than as evidence that any of these four Value variants is a strong standalone NGL signal. Separately: NEITHER Carry tenor (F2-F4 nor F2-F14) has been re-verified for liquidity or the near-tenor heating-season seasonality concern that originally motivated F4 over F1/F2 as the near leg (see the callout in the Overview and research/configs/ngl.py) — these numbers are internally consistent and correctly computed on the current config, but both tenor pairs remain provisional pending that re-check.
