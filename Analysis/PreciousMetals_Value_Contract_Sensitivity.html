Precious Metals Risk Premia — Value Contract Sensitivity

Products: Gold, Silver, Copper_COMEX, Platinum, Palladium (COMEX/NYMEX). Baseline: Value anchored on F8. This report reruns the ENTIRE pipeline — all 4 individual strategies (Precious Metals has a single Carry tenor pair, F1-F2, unlike Metals' two-tier F1-F3/F1-F13), all 4 portfolio combine methods, full-sample/regime/ expanding-window tables — three more times, each time with Value's anchor contract changed to F1, then F2, then F3. Momentum and the Carry/Carry-Momentum tenor pair are held EXACTLY as locked in research/configs/precious.py — only VALUE_CONTRACT changes. Lookback (1260d), threshold (±10%), and execution lag (shift_n=2) are unchanged from the F8 baseline in every variant.

1. Overview

Value is a long-run mean-reversion signal: it compares one point on the futures curve to that same point's own trailing moving average, and bets the price reverts toward that average when the deviation is large enough to clear a threshold. The baseline uses F8 as the anchor, deliberately further from the front of the curve than Momentum and Carry (which both operate on F1/F2). Moving the anchor to F1, F2, or F3 asks whether the near-contract price mean-reverts to its own 5-year moving average instead — a different, shorter-horizon-feeling question than F8's curve-structural read, even though the lookback window (1260 trading days) and threshold (±10%) stay identical.

Precious Metals' own Carry tenor pair (F1-F2, re-derived from real trade-volume data, not just quote availability — Platinum and Palladium are only genuinely liquid through F1-F2) is a different, shorter tenor than Metals' F1-F3/F1-F13 pairs, so this asset class only has 4 locked strategies (Momentum, Carry F1-F2, CarryMom F1-F2, Value), not 6. The portfolio combine methods therefore combine 4 sleeves here, not 6.

1.1 What's held fixed across all four variants (F8 baseline, F1, F2, F3)

  • Momentum: 3-way MA-crossover composite, (1,20)/(5,60)/(20,250), shift_n=1
  • Carry V1(Level)+V2(Z-score) composite: F1-F2 tenor pair (Precious Metals' single locked pair), z-window=252, shift_n=1
  • Carry-Momentum (V3): F1-F2 tenor pair, horizon=20, shift_n=1
  • Value lookback (1260d), threshold (±10%), execution lag (shift_n=2) — only the anchor CONTRACT changes
  • Transaction cost: 5bps round-trip. Products: Gold, Silver, Copper_COMEX, Platinum, Palladium, equal-weighted. Regimes: R1 Supercycle Unwind (2011-2015), R2 Recovery/Stabilization (2016-2019), R3 COVID Shock (2020-2021), R4 Post-COVID/Russia-Ukraine (2022-2026). Portfolio: the 4-sleeve "all reference strategies" aggregate (Momentum, Carry F1-F2, CarryMom F1-F2, Value) combined via Equal Weight, Inverse Vol (63d), Risk Parity (ERC, rolling 252d/21d rebal), and Return-Tilt ERC (tilt=0.5, illustrative midpoint).

Expanding-window tables here use the same convention as the Metals report: cumulative-sample performance snapshots through each regime boundary (2011→2015, 2011→2019, 2011→2021, 2011→latest), NOT a train/test split — these are fixed ex-ante rule-based signals, nothing is refit between windows.

StatArb caveat: StatArb is NOT used for Precious Metals at all (STATARB_ENABLED = False, tested and rejected across all 10 pairs including Gold-Silver and Platinum-Palladium — a genuine null result from prior project work). This report covers exactly the 4 strategies the config defines; there is no StatArb sleeve to exclude-and-disclose the way there is for NGL/Energy.

6. Findings / synthesis

Moving Value's anchor toward the front of the curve DECREASES Value's own standalone IR for Precious Metals — the opposite direction from the Metals report's finding. F8 +0.163 vs F1 +0.120, F2 +0.104, F3 +0.109. Unlike Metals, where F1 was the best of the four, here F8 (the baseline, further out on the curve) is the strongest and every front-of-curve variant is weaker. This is a genuinely different sensitivity direction per asset class, not a universal rule about which point on the curve Value should anchor to.

The regime sign pattern is NOT fully stable across contracts for this asset class — unlike Metals, at least one regime flips sign somewhere between F8 and F1/F2/F3 (see the per-regime comparison table above for the exact values).

Unlike Metals, Precious Metals already has a positive-crossing combine method at the F8 BASELINE, not at a front-curve variant: Inverse Vol (+0.015) is net-positive full-sample at F8. Moving Value's anchor to F1, F2, or F3 does NOT preserve this — every one of the 4 combine methods goes net-negative in all three front-curve variants (see the full comparison table above). So the direction of the effect is the reverse of Metals: there, moving toward the front of the curve CREATED a crossing (Return-Tilt ERC positive at F1/F2/F3); here, moving toward the front of the curve DESTROYS an existing one.

Caveat: this is only a first-order comparison against Metals' own finding, not a claim about WHY the direction differs. Precious Metals' curve dynamics (Gold/Silver/Copper-COMEX/Platinum/Palladium, several with pronounced backwardation/contango regime shifts of their own) are a different physical market from LME base metals, so a front-month price carrying more noise relative to its own 5-year mean-reversion target here is plausible but not verified beyond this sensitivity check.
